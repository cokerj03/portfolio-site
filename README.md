# Portfolio Site

Jamie Coker's personal portfolio — a single self-contained `index.html` (no build step, no dependencies besides Google Fonts). Links are already filled in for github.com/cokerj03 and your LinkedIn.

## Deploy to GitHub Pages (free)

1. Create a new GitHub repo named `cokerj03.github.io` (this exact name makes it your profile site at the root domain — use any other name if you'd rather it live at a sub-path).
2. Push this folder's `index.html` to that repo's `main` branch.
3. In the repo, go to **Settings → Pages**, set Source to `main` / `(root)`.
4. Your site is live at `https://cokerj03.github.io` (or `https://cokerj03.github.io/<repo-name>` for a non-profile repo) within a minute or two.

## Local preview

Just open `index.html` in a browser — it's fully static.

## What's in it

- Hero, About, Skills, Featured Projects (linking to the three project repos), Experience timeline, Education & Certifications, Contact
- Single dark theme, no light/dark toggle (a deliberate choice, not an oversight)
- No JS framework — vanilla HTML/CSS with one small inline SVG animation
